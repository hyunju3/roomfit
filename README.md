# 룸핏 — 치수로 하는 방 꾸미기

방과 가구 치수(cm)를 넣고, 가구를 끌어서 배치하고, 벽지·바닥재를 바꿔 3D로 미리 보는 웹 앱이에요.
휴대폰·태블릿 홈 화면에 설치해서 앱처럼 쓸 수 있어요 (PWA).

## 주요 기능
- **집 전체**: 여러 방을 붙여 집 모양 만들기, 층(다락) 나누기, 평면도 사진 깔고 축척 맞추기
- **배치**: 가구 끌어서 옮기기, 회전·복제·다른 방/보관함으로 옮기기, 가구 위에 올리기(TV·가전)
- **방·요소**: 방 크기, ㄱ·ㄴ자 방, 기둥, 여닫이·슬라이딩 문, 창문, 콘센트, 스위치, 문턱·계단
- **3D·벽지**: 입체로 돌려보기, 벽마다 벽지, 바닥재, 내 사진으로 벽지·바닥재·가구 면(앞·뒤·옆·위)
- **점검**: 겹침, 가구·방문 가동 범위, 창문 가림, 통로 폭, 동선, 콘센트 거리, 햇빛, 빈 자리에 맞는 가구
- **도구**: 벽지 롤 계산기, 바닥재 계산기, 배치안 A/B 비교(2D·3D), 살 가구 목록, JSON 백업
- **사용법**: 각 탭에 처음 들어가면 그림 설명이 나와요. 위쪽 `?` 로 다시 보기

## 휴대폰에 설치하기
1. 이 저장소의 GitHub Pages 주소를 휴대폰 브라우저로 열어요.
2. **아이폰(사파리)**: 공유 버튼 → *홈 화면에 추가*
3. **갤럭시(크롬·삼성 인터넷)**: 메뉴(⋮) → *홈 화면에 추가* 또는 *앱 설치*

## GitHub Pages 켜기
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열려요.

## 파일
- `index.html` — 앱 전체 (HTML·CSS·JS 한 파일)
- `manifest.webmanifest`, `icons/` — 홈 화면 설치용 정보와 아이콘
- `sw.js` — 인터넷 없이도 열리게 하는 캐시. 앱을 고치면 `VERSION` 값을 올려주세요.

## 데이터
모든 내용은 그 기기 브라우저(localStorage)에 저장돼요. 다른 기기로 옮길 때는 *도구 → 데이터 → JSON 복사/불러오기*를 써요.

## 벽지 붙이기
도구 탭의 *벽지 붙이기 · 전개도 · 재단표*: 최소 사용·깔끔하게 모드, 벽별 폭 번호와 이음매, 롤별 재단표, 구매 목록, 붙이는 순서 9단계(그림·체크리스트).

## 새 기능을 추가할 때
`index.html`의 `GUIDES` 배열에 설명(제목·단계·탭)을, `GUIDE_IMG`에 그림(SVG)을 추가하면
그 탭에 처음 들어갈 때 사용법이 자동으로 나와요.
